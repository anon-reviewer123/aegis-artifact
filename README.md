# Aegis Artifact

Anonymized artifact for the Aegis paper.

- `pipeline/` - the Aegis implementation: static analysis, MCVP synthesis and
  validation, the eight invariant templates, obligation compilation,
  SMTChecker/Eldarica backend, repair loop, tests, and benchmark contracts.
  See `pipeline/README.md` for setup and usage.
- `census/` - contract sources, per-contract taxonomy labels, and class
  descriptions for the mainnet callback census.
